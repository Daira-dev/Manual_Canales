Manual Técnico

Documentación técnica resumida de la plataforma web CANALESW, desarrollada para la Asociación Civil Canales. Este documento refleja el estado actual del proyecto y podrá ampliarse durante las siguientes etapas de desarrollo.

1. Objetivo

El proyecto tiene como objetivo desarrollar una nueva plataforma web para la Asociación Civil Canales, centralizando la información institucional y proporcionando herramientas para la gestión de contenidos y usuarios.

La plataforma contempla además criterios de accesibilidad e inclusión, especialmente relacionados con la comunidad sorda y el uso de Lengua de Señas Argentina (LSA).

2. Tecnologías

  • React
  • Laravel
  • PHP
  • JavaScript
  • HTML5
  • CSS3
  • Base de datos
  • Git / GitHub

3. Arquitectura general

El sistema se organiza mediante una arquitectura cliente-servidor, separando la interfaz de usuario de la lógica del servidor y la persistencia de datos.

4. Frontend

El frontend contiene la interfaz visual de la plataforma y permite al usuario navegar por las diferentes secciones del sitio.

Actualmente se encuentra en desarrollo y comprende principalmente la presentación institucional, navegación, autenticación y funcionalidades relacionadas con publicaciones.

5. Backend

El backend se desarrolla utilizando Laravel y concentra la lógica del sistema, el procesamiento de solicitudes y la comunicación con la base de datos.

Durante la etapa actual se está comenzando con la implementación de los diferentes CRUD y módulos de gestión definidos en los requerimientos.

6. Base de datos

La base de datos almacena la información necesaria para el funcionamiento de la plataforma, incluyendo usuarios, publicaciones y los futuros módulos de gestión.

El modelo de datos se encuentra en proceso de implementación y podrá actualizarse a medida que avance el desarrollo de los módulos definidos en la especificación de requisitos.

7. Control de versiones

El desarrollo utiliza Git para el control de versiones y GitHub como repositorio remoto.

El uso de ramas permite trabajar de manera independiente sobre diferentes funcionalidades y posteriormente integrar los cambios al proyecto principal.

8. Estado actual
