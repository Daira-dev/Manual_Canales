01
INTRODUCCIÓN

Descripción general

CANALES es una plataforma web desarrollada para centralizar información institucional y ofrecer herramientas de gestión para la Asociación Civil Canales.

El sistema contempla distintos perfiles de usuario y módulos destinados a la administración de contenidos, capacitaciones, inscripciones, materiales educativos y donaciones.

Su desarrollo utiliza una arquitectura modular que permite separar responsabilidades, organizar las funcionalidades y facilitar el mantenimiento de la aplicación.

03
ORGANIZACIÓN

Estructura del proyecto

El proyecto organiza sus componentes en directorios diferenciados para separar las responsabilidades del servidor, la interfaz y los recursos compartidos.

app/ Controladores, modelos y lógica de aplicación.
routes/ Definición de rutas web y endpoints de la API.
database/ Migraciones, seeders y archivos de base de datos.
frontend-react/ Aplicación React, componentes, páginas y servicios.
resources/ Recursos y vistas del backend.
public/ Archivos públicos y recursos accesibles de la aplicación.

La estructura representa los directorios principales conocidos del proyecto. La ubicación de algunos módulos puede variar según su organización interna.

04
SERVIDOR

Backend y API

El backend está desarrollado con Laravel y proporciona los servicios que permiten al frontend consultar, registrar, modificar y administrar la información.

Responsabilidades principales

  • Procesamiento de solicitudes HTTP.
  • Validación de los datos recibidos.
  • Aplicación de reglas de negocio.
  • Administración de usuarios, roles y permisos.
  • Acceso y persistencia de información.
  • Comunicación con servicios externos.

Comunicación mediante API

El frontend realiza solicitudes HTTP a los endpoints del backend. Laravel procesa cada solicitud y devuelve respuestas que permiten actualizar la información presentada en la interfaz.

05
INTERFAZ

Frontend

La interfaz está desarrollada con React y organizada mediante páginas y componentes reutilizables que representan las distintas áreas funcionales del sistema.

Características principales

  • Organización de la interfaz mediante componentes.
  • Navegación entre páginas y módulos.
  • Gestión de estados e interacción con el usuario.
  • Consumo de los servicios proporcionados por la API.
  • Centralización de solicitudes HTTP mediante servicios.

Entorno de desarrollo

Vite permite ejecutar el frontend durante el desarrollo y generar los archivos compilados necesarios para su publicación.

06
DATOS Y SEGURIDAD

Base de datos y autenticación

La persistencia de información se gestiona mediante modelos y migraciones de Laravel, que permiten definir las entidades, sus atributos y las relaciones entre ellas.

Principales áreas de información

  • Usuarios y perfiles.
  • Roles y permisos.
  • Publicaciones y contenidos institucionales.
  • Capacitaciones e inscripciones.
  • Materiales educativos.
  • Donaciones y pagos.

Autenticación y autorización

El sistema utiliza Laravel Sanctum para la autenticación y Spatie Laravel Permission para administrar roles y permisos.
